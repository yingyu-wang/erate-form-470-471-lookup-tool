# Third-party components and data

The project's MIT license covers its original code and documentation. Dependencies retain their own copyright notices and licenses; the project license does not replace them. The generated Mint Glass app icon is supplied with this project.

The app uses .NET, Windows Forms, Microsoft.Data.Sqlite, SQLitePCLRaw, and SQLite. The macOS interface also uses Avalonia and its transitive graphics and platform dependencies, including SkiaSharp and HarfBuzzSharp. Package versions are specified in the project files; NuGet package metadata identifies each dependency's upstream license. Preserve upstream notices when redistributing dependencies or building custom packages.

- [.NET](https://github.com/dotnet/runtime)
- [Windows Forms](https://github.com/dotnet/winforms)
- [Microsoft.Data.Sqlite](https://github.com/dotnet/efcore)
- [SQLitePCLRaw](https://github.com/ericsink/SQLitePCL.raw)
- [SQLite](https://www.sqlite.org/copyright.html)
- [Avalonia](https://github.com/AvaloniaUI/Avalonia)
- [SkiaSharp and HarfBuzzSharp](https://github.com/mono/SkiaSharp)

The bundled California entity directory and C2 budget snapshot originate from USAC Open Data. They are external data, not project-authored code and are not relicensed by the project's MIT license. Live results and snapshots can differ; USAC remains the authoritative source. This is an independent application, not an official USAC product.
